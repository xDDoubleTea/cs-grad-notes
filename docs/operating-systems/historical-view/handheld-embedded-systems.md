# Handheld/Embedded systems

## Specialized OS

For handheld/embedded systems, the operating system are designed specifically for the hardware.

- Limited memory
- Slower processors (compared to desktop version)
- Battery consumption
- Special hardware like touch screen, gyro sensor, camera

## Examples

!!! example "Handheld"

    - Android based (GrapheneOS, LineageOS, PixelOS)
    - iOS, iPadOS (BSD based)
    - SteamOS (arch based)
    - OpenWrt (commonly used by routers)

!!! example "Embedded Linux"

    - Ubuntu touch
    - Arch Linux ARM
    - [LEGO EV3 official firmware](https://education.lego.com/en-us/downloads/mindstorms-ev3/software/), (proprietary so probably not linux)
    - [ev3dev](https://www.ev3dev.org/), debian based
    - Raspberry Pi OS
