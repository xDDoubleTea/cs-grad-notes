# Distributed systems

## Peer-to-Peer

- Every machine is identical in its role

!!! example

    - bitTorrent
    - Internet
    - Netbird

## Client-Server

- One centralized machine, clients connects to server

!!! example

    - Minecraft server
    - OpenVPN server
    - Nextcloud server
    - ...

## Cluster

- Cluster computers share storage and linked via LAN or faster interconnect
- **對外視為一個服務**
- **需要management layer**

!!! example

    - K8s
