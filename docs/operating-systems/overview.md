# Overview

## 為何要有作業系統？

### Batch

優點：簡單直觀

1. 早期只有`batch`，程式需要完全跑完才能執行下一個程式
2. `I/O`系統速度比`CPU`慢非常多，導致`CPU`常常處在`idle`狀態
3. 人們想要跟電腦有互動，但因為`I/O`太慢，而且程式在跑的時候無法中斷，導致輸入一個訊號可能要很久才能拿到回應

於是人們開始思考如何降低`CPU`的`idle`時間
